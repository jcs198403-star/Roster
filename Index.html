Quick 2-Minute Google Sheet Setup:
  1. Open a new Google Sheet.
  2. Go to Extensions > Apps Script in the top menu.
  3. Paste the copied Apps Script code into Code.gs.
  4. Click Deploy > New deployment. Choose Web app.
  5. Set Who has access to "Anyone", click Deploy, copy the URL and paste it above!
